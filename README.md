# SuperMarket POS — downloads

SuperMarket POS is a point-of-sale app for supermarkets and minimarts in Ghana: fast selling, stock, Mobile Money, customers on credit, GRA E-VAT, owner reports, training mode — on Windows and Mac, working offline.

**Get the latest version:** [Releases](https://github.com/enochessoun-ops/supermarket-pos-downloads/releases/latest)

| Computer | Download |
|---|---|
| Windows 10/11 | `SuperMarket-POS-<version>-windows-setup.exe` |
| Mac with Apple chip (M1–M4) | `SuperMarket-POS-<version>-mac-apple-silicon.dmg` |
| Mac with Intel chip | `SuperMarket-POS-<version>-mac-intel.dmg` |
| User Guide (PDF) | `SuperMarket-POS-<version>-User-Guide.pdf` |

Every release has a `SHA256SUMS.txt` so you can check a download. The app tries everything free for 14 days; a licence key comes from your supplier.

## Updates
Installed copies check `update-feed.json` in this repository. The feed is **signed**: the app offers a download only if the signature matches the supplier's key built into the app, and keeps the installer only if its SHA-256 matches. Version 2.0.0 users: set **Settings → Backup & Restore → Update Feed URL** to

```
https://raw.githubusercontent.com/enochessoun-ops/supermarket-pos-downloads/main/update-feed.json
```

This repository holds only installers, the update feed and documentation. The source code is not published.
